E-Commerce Sales Dashboard

1. Project Overview

This project analyses e-commerce sales data to understand revenue, profit, orders, product performance, and sales trends.

2. Objective

To build an interactive Power BI dashboard that helps businesses monitor sales performance and make data-driven decisions.

3. Tools Used

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Visualisation

4. Key Performance Indicators (KPIs)

- Total Revenue
- Total Profit
- Total Orders
- Total Quantity Sold
- Profit Margin (%)

5. Dashboard Visualisations

- Revenue by Category
- Top 5 Products by Revenue
- Revenue by Region
- Revenue by Sales Channel
- Monthly Revenue Trend

6. Interactive Features

- Region slicer
- Category slicer

7. Key Learning Outcomes

- Data cleaning and preparation
- Creating DAX measures
- Building interactive dashboards
- Analysing business performance

8. Project Status

Completed
