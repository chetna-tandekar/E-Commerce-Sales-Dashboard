E-Commerce Sales Dashboard

Project Overview

This project focuses on analyzing E-Commerce sales data and creating an interactive dashboard using Microsoft Power BI.

The dashboard helps visualize sales performance and understand business trends through interactive charts and visualizations.

Tools & Technologies

- Microsoft Power BI
- CSV Dataset

Project Features

- Interactive sales dashboard
- Sales performance visualization
- Data analysis using Power BI
- Charts and graphical representations

Project Files

- "Ecommerce_Sales_Dashboards.pbix" – Power BI dashboard file
- "ecommerce_sales.csv" – Dataset
- "Ecommerce_Dashboard.png" – Dashboard screenshot

Project Objective

To develop an interactive sales dashboard that presents business data in an easy-to-understand visual format.
